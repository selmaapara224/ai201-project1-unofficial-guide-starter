# Intel-Mac pins — see "Environment Setup Note" in README.md.
# PyTorch dropped macOS x86_64 wheels after 2.2.2, which caps Python at 3.12.
# torch 2.2.2 predates the NumPy 2 ABI, so numpy and scipy must stay on 1.x-compatible
# releases. Harmless on Apple Silicon: torch 2.2.2 ships arm64 wheels too.
